## 显著变更

### 修复
- **`flnd/client.go`**：`PublishTransaction` 曾将一个动态字符串作为格式字符串传给 `fmt.Errorf`；由于不需要格式化，已改用 `errors.New`。
- **测试辅助函数**：`createTestTempDir` 恢复了其真正的 `os.MkdirTemp` 实现（此前曾被替换为某开发者机器上的硬编码绝对路径）。
- **测试命名**：一个名为 `TestMain` 但接收 `*testing.T`（而非 `*testing.M`）的函数，实际上从未起到包测试入口钩子的作用——它只是以一个容易引起误解的名字运行了一项非常繁重、会启动真实守护进程的测试。已重命名为 `TestManualFlndTestnetLaunch`。
- **集成测试**：`flnd/` 目录下全部 4 个测试文件都会启动真实的 `flnd` 守护进程和/或需要实时的测试网连接。现已置于 `//go:build integration` 构建标签之后，因此 CI 中使用的普通 `go test ./...` 会干净地跳过它们；仍可通过 `-tags=integration` 显式运行。

### CI
- 新增 `.github/workflows/ci.yaml`：在推送到 `main` 分支及提交 Pull Request 时运行 `go build`、`go vet` 和 `go test`。
